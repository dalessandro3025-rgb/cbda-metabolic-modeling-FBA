# CBDA Metabolic Modeling in Saccharomyces cerevisiae

## Overview

This repository contains the computational workflow developed during an Institutional Scientific Initiation project at the Federal Institute of São Paulo (IFSP).

The project aims to investigate metabolic engineering strategies for improving cannabidiolic acid (CBDA) production in Saccharomyces cerevisiae using genome-scale metabolic models and Flux Balance Analysis (FBA).

## Objectives

- Import and validate the iMM904 metabolic model.
- Introduce the heterologous CBDA biosynthetic pathway.
- Perform Flux Balance Analysis (FBA).
- Identify metabolic bottlenecks.
- Evaluate engineering strategies involving redox balance and precursor availability.

## Tools

- Python 3.11
- COBRApy
- GLPK
- Jupyter Notebook

## Current Status

- Computational environment configured
- Import and validation of the iMM904 metabolic model
- Baseline FBA simulations completed
- Implementation of the heterologous pathway (in progress)
- Flux Variability Analysis (planned)
- Gene deletion analyses (planned)
- OptKnock optimization (planned)
